# Code signing policy

Free code signing provided by [SignPath.io](https://about.signpath.io/),
certificate by [SignPath Foundation](https://signpath.org/).

The Windows programs of anySCP (`anySCP-<version>-windows-x64.exe` and
`anySCP-<version>-windows-arm64.exe`, and every program file and library
inside them) are built from this repository by its GitHub Actions workflow and
signed only after a maintainer has approved the release.

## Team roles

- Committers and reviewers: [Bruno](https://github.com/brunosalezze)
- Approvers: [Bruno](https://github.com/brunosalezze)

## Privacy policy

This program will not transfer any information to other networked systems
unless specifically requested by the user or the person installing or
operating it. anySCP connects only to the servers (and proxies and jump hosts)
that you enter, to transfer the files you choose. It has no telemetry and does
not check for updates.
